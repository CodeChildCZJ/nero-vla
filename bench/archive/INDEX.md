# bench/archive — 一次性诊断与审计脚本索引

这些脚本不在复现主干上。它们是做这套 benchmark 期间为回答某个具体质疑而写的一次性工具,
原样保留是为了让结论可复核 —— 每一条结论下面都有代码。

「得出的结论」一栏只写脚本自己记录下来的实测结果。脚本只写了方法、没有把结果写进
源码的,一律写 `(未记录)` —— 那不代表没跑过,只代表结论落在别处(日志 / JSON 产物 /
对话记录),不能从这个文件里核实。

路径已改为仓库自包含:`BENCH` = `Path(__file__).resolve().parents[1]`,跨机 / checkpoint /
数据集路径走 `NERO_ROOT` / `NERO_CKPT` / `NERO_DATA` / `NERO_DATA_V30` / `NERO_REMOTE_HOST`
环境变量。除路径常量外,逻辑一字未动。
